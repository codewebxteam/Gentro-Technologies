# Gentro Technologies

Official web portal and marketing platform for **Gentro Technologies** — WhatsApp Marketing API & Smart CRM Software.

## 🚀 Features
- **Affordable Messaging**: Send WhatsApp marketing broadcasts at ₹0.15 / message.
- **Enterprise Software**: Complete WhatsApp API software license at ₹7,999 / year.
- **Built-in Legal & Compliance Pages**:
  - `/privacy-policy`
  - `/refund-policy`
  - `/terms-and-conditions`
  - `/about`
  - `/services`
  - `/contact`
- **Instant Booking**: Google Calendar meeting integration.
- **Modern Responsive Design**: Built with Next.js App Router, Tailwind CSS, Lucide Icons, and full mobile optimization.

## 🛠️ Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Google Fonts (Plus Jakarta Sans)

## 🏃 Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📦 Build for Production

```bash
npm run build
```
